# Kethireddy Kondareddy — Professional Portfolio

Created from the uploaded resume.

## Run
Open `index.html` in a browser or use VS Code Live Server.

## Profile photo
The resume does not contain a profile photo, so the portfolio currently uses a KK initials avatar. To add a photo, create `images/profile.jpg` and replace the avatar in `index.html` with:
`<img src="./images/profile.jpg" alt="Kethireddy Kondareddy">`
